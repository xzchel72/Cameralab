# CameraLab — сравнение камер смартфонов

Одностраничный адаптивный сайт на HTML, CSS и JavaScript. Сравнивает фотосистемы OPPO Find X8 Ultra и iPhone 16 Pro Max.

## Файлы
- `index.html` — содержание страницы
- `style.css` — оформление, адаптация под телефон и компьютер
- `script.js` — переключение темы и анимация звёзд

## Публикация через GitHub Pages
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в него эти три файла и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. После публикации сайт появится по адресу вида `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Важно
Характеристики приведены для ознакомления. Перед публикацией в качестве технического обзора проверь значения по официальным спецификациям и учитывай, что качество фото нельзя оценивать только по мегапикселям.
